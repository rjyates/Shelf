# Approved Shelf design direction

Baseline: version 3, approved 2026-10-30. See `docs/design/v3.md` and `docs/design/shelf-v3.png`.

- Background `#171916`; panels `#21241f`; text `#e4dcc8`; brass `#b5a16b`; moss `#7f9274`.
- Instrument Serif display, IBM Plex Sans UI, IBM Plex Mono metadata. Fonts are locally bundled under their OFL licenses.
- Sidebar-led catalogue layout, generous editorial headings, fine brass rules, quiet celestial arcs, small engraved botanical details.
- Dark journal surfaces; rich cover art supplies additional colors when real covers are available.
- Responsive navigation, visible focus, accessible progress values, readable contrast, and reduced-motion support.
- Preserve this direction during incremental work. No fresh discovery gallery or palette replacement is needed.

## Book Orbit as UX reference (required)

Book Orbit is the **layout and interaction** reference for Shelf product surfaces. Visual style stays Shelf journal (this file + `docs/design/v3.md`), not Book Orbit’s turquoise chrome.

Before designing or extending Shelf UI (web journal, mobile e-ink/LCD chrome, library org, stats, settings—not the embedded Foliate host), agents must:

1. **Look at Book Orbit** — public site / docs, live demo when available, and the vendored reader + feature code under `web/orbit-reader/vendor/bookorbit/` (and upstream [bookorbit/bookorbit](https://github.com/bookorbit/bookorbit) when needed).
2. **Extract UX, not pixels** — information architecture, primary actions, density of controls, empty/loading/error patterns, how reading/progress/marks/settings are reached. Prefer proven BO flows over inventing parallel ones.
3. **Implement in Shelf’s skin** — same jobs and hierarchy, expressed with Shelf tokens, type, ornaments, and e-ink rules (light paper / black ink on mobile; journal palette on web). Do not copy BO colors, fonts, or component kits wholesale.
4. **Foliate exception** — the hosted Book Orbit Foliate reader under `/reader` keeps BO chrome as shipped (decision 0004 / `docs/parity.md`). Do not restyle that SPA to the journal theme while it remains the shared reader surface.

When Picasso is used for Shelf UI work, treat this section as a hard constraint alongside the palette and anti-slop rules.
