# Shelf mobile

One Flutter/Dart application for Android and iPhone. Use the Flutter version in the repository's `.flutter-version` file.

Create your account in the Shelf web app, then enter your HTTPS server address and sign in here. This is one Flutter app for Android and iPhone. The foundation supports catalogue, metadata, page progress, and opening EPUBs in a WebView against the shared Book Orbit reader.

Product shape (see [roadmap](../docs/parity.md)): e-ink vs LCD display profile from first-run onboarding (retoggle in Display settings); Save offline caches EPUB bytes; the sync outbox flushes on refresh and when connectivity returns (including HTTP 5xx failures). Cached opens on Android e-ink (or any offline device) use Readium (`flutter_readium`) with bookmarks/highlights/stylus ink; online LCD/iPhone keep Foliate. Accelerated live ink is **SuperNote Nomad only** today (`EinkRefresh` / SPEED+A2); other Android tablets use Flutter Canvas. Roadmap (generic tablet drawing → golden devices): [Nomad stylus notes](../docs/research/nomad-stylus.md).

From this directory, run `flutter pub get --enforce-lockfile`, `flutter analyze --fatal-infos`, and `flutter test`. Launch with `flutter run` on a configured device or emulator. A phone cannot reach a server bound only to another computer's loopback interface; use the HTTPS reverse-proxy setup described in the [root README](../README.md).

For USB e-ink tablets (SuperNote Nomad) talking to a host loopback server via `adb reverse`, use the project skill [`.cursor/skills/shelf-eink-android/SKILL.md`](../.cursor/skills/shelf-eink-android/SKILL.md) and optional `device-test.env` (see `device-test.env.example`).

GitHub builds Android on Linux and an unsigned iPhone IPA on macOS. A sideload tool can re-sign that IPA with your Apple ID. See [release documentation](../docs/releases.md) for artifact and signing limits. Platform directories are generated by the Flutter SDK; app logic and UI live in `lib/`.
